# Glitter AI Assignment

## Project Overview
This repository contains my submission for the Glitter AI Internship Assignment.

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- REST APIs

### Frontend
- React.js

### Features
- Image generation job creation
- Job status tracking
- API documentation with Swagger
- React frontend

## Run Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Run Frontend

```bash
cd frontend
npm install
npm start
```
